# One Word for the Boss

A make.fun bounty entry: a small deterministic Python program that writes
exactly one word — "ASAP" — to `/output/entry.txt`, with no trailing newline.
It uses only the standard library, creates the output directory when needed,
and produces the same four bytes on every run.
